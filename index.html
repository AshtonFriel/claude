How it works

01

Bring your own data

Type an array, a weighted graph, an operation script, or a start node. Atlas parses it, validates it, and drops it straight into the stage.

02

Step, don't guess

Play forward, step back one operation, or drag the timeline to any point in the run. The code panel highlights the exact line responsible for the frame on screen, in Java, JavaScript, or Python.

03

Read the cost, then prove it

On sorting and searching topics, the growth chart runs the topic's own step generator across input sizes and plots steps executed — the Big-O shape is measured, not asserted.
